# Medical Data History SQL Project

## Project Overview
This project focuses on analyzing medical and patient-related data using MySQL. It includes SQL queries designed to retrieve, filter, summarize, and analyze information from patient, admission, province, and doctor records.

## Tools Used
- MySQL
- SQL

## Project Objectives
- Retrieve patient information using SELECT statements.
- Filter records using WHERE, LIKE, and BETWEEN.
- Combine data from multiple tables using JOIN.
- Perform calculations and summaries using aggregate functions.
- Analyze patient admissions and diagnoses.
- Use subqueries, GROUP BY, HAVING, and UNION.
- Calculate BMI and identify patients based on health-related criteria.

## SQL Concepts Covered
- SELECT and DISTINCT
- WHERE, AND, OR, LIKE, BETWEEN
- ORDER BY
- GROUP BY and HAVING
- COUNT, SUM, MIN, MAX
- INNER JOIN
- Subqueries
- UNION
- CASE statements
- String and date functions
- Data updates

## Project Work
The project contains 34 SQL queries covering different types of medical data analysis, including patient details, admission records, diagnoses, doctor information, and BMI calculations.

## Files Included
- `Medical_Data_History_SQL_Project.sql` – SQL script containing the project queries.
- `Medical_Data_History_SQL_Project.docx` – Project documentation.

## Key Learning Outcomes
Through this project, I practiced writing SQL queries, combining related tables, summarizing data, and extracting meaningful information from a medical database.
